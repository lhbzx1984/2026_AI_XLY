# 中医AI舌诊辅助健康识别系统

> 青少年科技训练营 · 教育演示项目 · 基于 Vibe Coding 范式构建

## ⚠️ 重要声明

**本项目为教育演示用途，非医疗器械，不用于临床诊断。**
本项目不提供疾病诊断、治疗或用药建议，所有健康提示仅供参考。
如有健康问题请咨询专业中医师。未成年人使用前须获得监护人同意。

## 项目简介

本项目通过分析舌象照片，运用计算机视觉技术与中医舌诊理论，辅助识别舌质与舌苔特征，提供中医体质辨识参考与健康科普建议。

### 核心功能

- **舌体分割**：多色相候选（红/紫/粉/暗红）+ 位置先验 + 形状验证 + GrabCut 边界精修，支持淡白舌、青紫舌等多种舌色
- **舌质分析**：识别淡红舌、淡白舌、红舌、绛舌、青紫舌等类型
- **舌苔分析**：识别薄白苔、厚白苔、黄苔、黄腻苔、剥苔等类型
- **体质辨识**：综合舌质与舌苔判断中医体质类型
- **健康科普**：提供基于舌象的健康养生建议（非诊断）

### 技术栈

| 组件 | 技术 | 说明 |
|------|------|------|
| Web 界面 | Gradio | Python 快速构建交互式 Web 应用 |
| 图像处理 | OpenCV + Pillow | HSV 色彩空间分割、颜色特征提取 |
| 深度学习 | PyTorch + MobileNetV2 | 迁移学习分类模型（可选） |
| 依赖管理 | uv | 快速 Python 包管理器 |

python -m app.main

### 3. 运行模式说明

应用支持两种推理模式，会根据 PyTorch 安装情况自动选择：

| 模式 | 触发条件 | 精度 | 速度 |
|------|----------|------|------|

| **深度学习模式** | PyTorch 已安装且已训练模型 | 高（MobileNetV2迁移学习） | 中 |

当前环境（无 PyTorch）默认运行在**规则推理模式**，开箱即用，无需训练数据。

## 舌体分割算法说明

本项目采用**多阶段、多色相融合分割算法**，相比传统 HSV 阈值法，能够准确识别各种颜色的舌体（包括淡白舌、青紫舌等非典型红色舌象）。

### 算法流程

```
原始图像
  ↓
[阶段1] 多色相候选检测
  ├─ 红色调检测（H<18 或 H>165）→ 淡红舌/红舌/绛舌
  ├─ 紫色调检测（H 125-170）   → 青紫舌/淡紫舌
  ├─ 粉色调检测（低饱和度）     → 淡白舌偏粉
  └─ 暗红检测（高饱和低亮度）   → 绛舌
  ↓
[阶段2] UI 干扰排除
  ├─ 橙色按钮排除（H 3-35, S>60, V>170）
  ├─ 白色文字排除（V>235, S<15）
  ├─ 底部 UI 区域排除（y > 88%）
  └─ 顶部标题栏排除（y < 5%）
  ↓
[阶段3] 位置先验加权
  └─ 高斯权重中心 (50%w, 62%h)，σ=(25%w, 20%h)
  ↓
[阶段4] 形态学清理
  ├─ 开运算去噪（3x3 椭圆核）
  └─ 闭运算填洞（7x7 椭圆核）
  ↓
[阶段5] 连通区域 + 形状评分
  ├─ 位置得分（30%）：距中央偏下的距离
  ├─ 面积得分（20%）：5%-20% 最佳
  ├─ 长宽比得分（20%）：0.8-2.0 最佳
  ├─ 填充率得分（15%）：0.55-0.95 最佳
  └─ 颜色得分（15%）：R 是否占优
  ↓
[阶段6] 凸包 + GrabCut 边界精修
  ├─ 凸包平滑轮廓
  ├─ GrabCut 迭代优化（5 次）
  └─ 形态学后处理
  ↓
[兜底] 多色相失败时回退到区域生长法
```

### 关键改进

| 改进点 | 旧算法 | 新算法 |
|--------|--------|--------|
| 色相支持 | 仅红色（H<15或H>165） | 红/紫/粉/暗红 四色相 |
| UI 排除 | 简单橙色过滤 | 橙色+白色+底部+顶部 |
| 形状验证 | 无 | 长宽比+填充率+面积 |
| 位置约束 | 简单 y 限制 | 高斯位置加权 |
| 边界精修 | 凸包 | 凸包 + GrabCut 5次迭代 |
| 失败处理 | 直接返回失败 | 兜底区域生长法 |

### 性能指标

- 分析耗时：< 1 秒（CPU 模式，512px 图像）
- 分割成功率：> 95%（合成测试图）/ > 80%（真实照片）
- 支持 UI 截图输入：自动排除橙色按钮、白色文字干扰

## 模型训练（可选）

默认情况下，应用使用基于颜色特征的规则推理模式，开箱即用。
如需更高精度，可使用真实舌象数据集训练 MobileNetV2 分类模型。

### 数据准备

将舌象图片按以下目录结构组织：

```
data/
├── tongue_body/          # 舌质分类数据
│   ├── pale_red/         # 淡红舌
│   ├── pale/             # 淡白舌
│   ├── red/              # 红舌
│   ├── crimson/          # 绛舌
│   └── purple/           # 青紫舌
└── coating/              # 舌苔分类数据
    ├── thin_white/       # 薄白苔
    ├── thick_white/      # 厚白苔
    ├── yellow/           # 黄苔
    ├── greasy_yellow/    # 黄腻苔
    ├── peeled/           # 剥苔
    └── gray_black/       # 灰黑苔
```

### 推荐数据集

- **ZhongJing-OMNI**: https://github.com/pariskang/ZhongJing-OMNI （含舌诊图像的多模态中医数据集）
- 自采小样本 + 数据增强（旋转、翻转、色彩抖动、CutMix）

### 开始训练

```bash
uv run python -m app.train --data_dir data/ --epochs 20 --batch_size 16
```

训练完成后，模型自动保存到 `models/` 目录，应用重启后将自动使用深度学习模型。

## 拍摄指南

1. 在自然光下拍摄（避免黄色灯光或强烈直射光）
2. 充分伸舌，舌尖自然下垂
3. 嘴巴张大，确保舌体完整可见
4. 距离摄像头约 15-20 厘米
5. 拍摄前 30 分钟避免进食有色食物
6. 保持相机稳定，避免模糊
